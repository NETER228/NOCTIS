# Фотоархив

Учебный персональный сайт каталогизации цифровых фотографий на PHP 8.1+ и MySQL 8.0+.

## Запуск

1. Установите PHP с расширениями `pdo_mysql`, `fileinfo`, `gd` и MySQL (например, через XAMPP).
2. Выполните `schema.sql` в MySQL.
3. Скопируйте `config.example.php` в `config.php` и укажите подключение к БД и пароль администратора.
4. Откройте папку сайта через веб-сервер. Для локальной проверки можно запустить `php -S localhost:8000` из этой папки.
5. Откройте `http://localhost:8000`.

Чтобы заполнить пустую базу демонстрационными альбомами и фотографиями, выполните `php seed_demo.php` после настройки `config.php` и импорта `schema.sql`. Исходные изображения лежат в `assets/`. Повторный запуск не создаёт дубликаты. Снимок чёрной дыры предоставлен владельцем коллекции; изображения `architecture.png` и `nature.png` созданы с помощью ИИ. Ещё шесть снимков найдены через Pinterest и опубликованы по лицензии Unsplash. Авторы и ссылки приведены в [PHOTO_CREDITS.md](PHOTO_CREDITS.md).

На подготовленном компьютере можно запустить `start-local.ps1` из PowerShell: скрипт включает локальную базу MySQL на порту 3307 и веб-сервер, затем открывает сайт в браузере. На другом компьютере сначала установите PHP и MySQL и укажите свой порт в `config.php`.

Пароль администратора нужен для добавления, редактирования и удаления данных. Фотографии хранятся в `uploads/`, метаданные — в MySQL. Поддерживаются JPEG, PNG и WebP до 10 МБ. При загрузке GD создаёт безопасную копию изображения, отбрасывая исходные метаданные.

Для публикации используйте HTTPS, смените пароль по умолчанию, ограничьте доступ к `config.php`, отключите показ ошибок PHP и настройте резервное копирование базы и папки `uploads/`.

`config.php` и загруженные через сайт файлы не отслеживаются Git. Репозиторий содержит пример конфигурации и демонстрационные изображения.
